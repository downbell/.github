# Downbell

**Uptime monitoring that rings your phone the moment a site goes down.**

[Downbell](https://downbell.app) checks your websites, APIs and cron jobs from three regions (North America, Europe, Asia) and alerts you only when two agree something is wrong.

- Phone push, email, Slack, Discord, Telegram and signed webhooks, on every plan
- Heartbeat monitoring for cron jobs, backups and scheduled workflows
- SSL certificate and domain expiry warnings
- Public status pages on your own domain
- Free for 50 monitors. Paid plans from $4/month

## Open source here

- [heartbeat-action](https://github.com/downbell/heartbeat-action): a GitHub Action that alerts you when a scheduled workflow stops running
